# عرين الموارد التجارية — Arin Web

Angular 16 company site mixing three design models:

- Cinematic dark hero, gold telemetry, trade-route map, and partner marquee
- Editorial cream pages, signal board, and page heroes
- Bilingual AR/EN structure, quote flow, catalogue, and private-label journey

## Run

```bash
cd arin-web
npm install
npm start
```

Open `http://localhost:4200`.

Default language is Arabic (RTL). Switch to English from the navbar.
